##  System Architecture (Typical)

- Document ingestion & parsing
- Chunking strategies tuned for retrieval geometry
- Embedding model selection based on accuracy–cost trade-offs
- Vector compression & indexing for memory efficiency
- Intent classification to constrain retrieval scope
- Redis semantic cache → conditional LLM invocation
- FastAPI service layer
- Dockerized deployment on **GCP / AWS**
- Centralized logging, monitoring, and versioning

Frameworks like **LangChain / LangGraph** are treated as **tools**, not dependencies.
